Para instalar no Android como aplicativo:
1. Publique esta pasta em um endereço HTTPS (GitHub Pages, Cloudflare Pages, Netlify etc.).
2. Abra o endereço no Chrome do Android.
3. Toque em “Instalar SOP-Z no Android” quando aparecer, ou menu ⋮ > Adicionar à tela inicial / Instalar aplicativo.

O app salva as tarefas no próprio aparelho usando localStorage.
Inclui backup/exportação e importação JSON.
